# CampusTrack

## Student Academic Management System

CampusTrack is a simple Python project made to help students manage basic academic information in one place.

## Features

- Student Profile Management
- Assignment Management
- Marks and Performance
- Academic Report
- Basic Input Validation
- Data Storage

## Technologies Used

- Python
- JSON
